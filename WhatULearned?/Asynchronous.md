- Asynchronous functions 
  - functions that can happen in the background while the rest of your code executes 

- callbacks 
  - in past, it was handled by callbacks.
  - it is a funciton passed into another function as an argument with is then invoken insde the outer function to complete some kind of routine or action. 

```js
  myDiv.addEventListener("click", function(){
  // do something!
})
```

- promise 
  - a promise is an object that might produce a value at some point in the future.
